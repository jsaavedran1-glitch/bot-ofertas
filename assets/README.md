# Recursos visuales

El renderizador funciona sin recursos externos y dibuja la marca tipográficamente.
Puedes añadir aquí un logo y fuentes con licencia, y después referenciarlos desde
`app/image_renderer.py`. Nunca incluyas imágenes de productos sin autorización.

## Tipografía

`fonts/Montserrat-Variable.ttf` es Montserrat (Google Fonts), licencia SIL Open Font
License 1.1 (`fonts/OFL.txt`). El renderizador usa sus pesos SemiBold, Bold, ExtraBold
y Black; si el archivo falta, vuelve a DejaVu/Arial.
